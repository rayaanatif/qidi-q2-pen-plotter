Project

A project keeps every drawing with its position, size, rotation and all the settings. If saving a file is blocked where you run this page, use Copy project and paste it into the SVG box later: pasted project text loads as a project. Snap: moving a drawing snaps its edges and centre to the sheet margins; hold Alt to move freely.

Placement

These four fields edit the selected drawing (click it in the preview or in the list above). Drag it in the preview to move it, or drag a corner square to resize it; the proportions stay locked. Drag the round handle above the box to rotate it (hold Shift to snap to 15°), or type an angle. Origin is where its lower-left corner lands, as pen position in machine X/Y.

Paper on the bed

The pen cannot reach the top of a full sheet (the cartridge hits the rear panel). Whole-page mode draws everything the pen can reach first, then you turn the sheet 180° in the same rectangle and a second file draws the rest. The crosses are drawn in both passes: if they line up as single crosses, the sheet went back correctly.

Left edge X and Rear edge Y below say where the sheet's rear-left corner is. The width and height are the portrait size; tick Landscape to swap them.

Left edge X is where the sheet's left edge sits on the bed (0 = against the left of the bed). Rear edge Y is where its back edge sits. Fit sets the size and origin to the usable area inside the margins. Support the overhanging part of the sheet at bed height (a block or board under it), otherwise the pen pushes it down and the lines go faint there. The bed mesh only covers the bed, so the overhang uses the edge values.

Colour in filled areas

Tone bands (how dark a colour is, 0 = white, 100 = black)
Line spacing for each band (mm)

Each filled shape is shaded by its own colour: lighter colours get sparse lines, darker ones get tighter lines, and the darkest get a cross-hatch. Gradients and colours the page can't read count as mid grey. Angle and the outline option below still apply.

The pen only has one colour, so a fill is a zigzag of pen lines. Set the spacing to about your pen's line width (0.4 to 0.7 mm for most gel pens) for a solid look. White or light fills are skipped in "Fill dark areas". Shapes stacked on top of each other are not hidden, so an area under a white shape still gets hatched.

Pens (colours)

Each stroke and fill takes the colour it has in the SVG. Pick which pen draws each colour (or Skip). You get one file per pen: fit that pen, run the file, then change pens and run the next. Near-white colours start as Skip.
